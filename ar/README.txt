کارت‌پستال‌های زنده (AR) — راهنمای آپلود
=========================================

1) این پوشه (ar) را از حالت zip خارج کنید.
2) به github.com بروید و ریپازیتوری mahsheedkhalaj.github.io را باز کنید.
3) Add file  ←  Upload files را بزنید.
4) کل پوشه‌ی «ar» را (خود پوشه، نه فقط فایل‌های داخلش) بکشید و داخل صفحه رها کنید.
5) پایین صفحه Commit changes را بزنید و ۱ تا ۲ دقیقه صبر کنید.
6) روی گوشی این آدرس را باز کنید:
   https://mahsheedkhalaj.github.io/ar/
7) «شروع» را بزنید، اجازه‌ی دوربین را بدهید و دوربین را روی کارت‌پستال بگیرید.

نکته‌ها
- بار اول حدود ۱۰ تا ۳۰ ثانیه طول می‌کشد تا کارت‌ها آماده شوند؛ دفعه‌های بعد سریع است.
- کارت‌ها را در نور خوب و بدون انعکاس شدید نگه دارید.
- ساختار پوشه نباید تغییر کند:
  ar/index.html

  ar/media/card2.jpg  card2.mp4
  ar/media/card3.jpg  card3.mp4
